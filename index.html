📖 Méthodologie de l'évaluation quantitative (Match Live)
Comment l'application calcule la note collective (N.Col) et la note individuelle (N.Ind) d'un cycle de sports collectifs d'invasion à partir des matchs Match Live (méthode quantitative, données chiffrées).
1. Répartition générale
proc = N.Ind (50%) + N.Col (50%)
NiveauComp.ConcertationProcédurale
1AC/3/3/14 (N.Ind /7 + N.Col /7)
2AC/4/3/13 (N.Ind /6.5 + N.Col /6.5)
3AC/5/3/12 (N.Ind /6 + N.Col /6)
Principe prioritaire pondéré à 40% selon le niveau : 1AC → Conservation · 2AC → Progression · 3AC → Repli défensif.
2. Note collective — N.Col

N.Col = 50% maîtrise (X) + 25% classement de gain de match (Y) + 25% motivation & coopération (Z), sur tous les matchs d'évaluation du cycle joués par l'équipe.

score = 0,4 × (principe prioritaire) + 0,2 × efficacité + 0,2 × indicateur A + 0,2 × indicateur B
ScoreNiveauPoints (X)
< 30%Niveau 11/3 de X
30% – 65%Niveau 21/2 de X
> 65%Niveau 3X en entier
Y_équipe = (colT × 0,25) ÷ rang  ·  rang = classement de gain de match (nombre de victoires uniquement ; égalité de victoires → même rang)
Z_équipe = motivation & coopération « Oui » ? colT×0,25 : colT×0,25 ÷ 2

Le « Oui/Non » de motivation & coopération se règle par équipe directement dans la grille collective (Match Live ou tableau manuel) — c'est le même champ dans les deux écrans.

Exemple (3AC, colT=6) — conservation 92%, progression 31%, efficacité 50%, repli 0%, classée 2ᵉ, motivation « Oui » :
score = 0,4×0 + 0,2×0,50 + 0,2×0,92 + 0,2×0,31 = 0,346 → Niveau 2 → X = 6×0,50×½ = 1,5 · Y = (6×0,25)÷2 = 0,75 · Z = 6×0,25 = 1,5 → N.Col = 1,5+0,75+1,5 = 3,75/6
3. Note individuelle — N.Ind
DimensionPoidsCalcul
Maîtrise technique35%passes réussies ÷ (passes réussies + pertes)
Implication30%min(1, ballons touchés ÷ (matchs × 6))
Apport offensif35%min(1, (buts×2 + passes déc.) ÷ (matchs × 1))
N.Ind = indT × (0,35 × conservation + 0,30 × implication + 0,35 × apport)
Exemple (3AC, indT=6) — 1 match, 2 ballons touchés, 2 passes réussies, 0 passe déc., 0 but :
conservation=1,0 · implication=0,33 · apport=0 → score=0,45 → N.Ind = 2,7/6
• Les % affichés se mettent à jour en direct à chaque match ajouté/modifié.
• Cliquer sur « ⚡ Calculer et enregistrer les notes » fige N.Ind/N.Col dans le bulletin de l'élève.
• Un % basé sur très peu d'occasions (ex. 1 seul repli observé) peut faire basculer tout un palier — à interpréter avec prudence sur peu de matchs.
📖 Méthodologie de l'évaluation qualitative (Grilles)
Comment l'application calcule la note collective (N.Col) et la note individuelle (N.Ind) d'un cycle de sports collectifs d'invasion à partir des grilles individuelle et collective (méthode qualitative, niveaux observés 1-2-3).
1. Répartition générale
Procédurale = N.Ind (50%) + N.Col (50%)
NiveauComp.ConcertationProcédurale
1AC/3/3/14 (N.Ind /7 + N.Col /7)
2AC/4/3/13 (N.Ind /6,5 + N.Col /6,5)
3AC/5/3/12 (N.Ind /6 + N.Col /6)
La note finale /20 = Comportementale + Conceptuelle + Procédurale.
2. Note individuelle — N.Ind

Basée sur les 1 à 2 critères individuels choisis pour le cycle. Pendant l'observation, chaque élève est situé sur un niveau de maîtrise (1, 2 ou 3) pour chaque critère ; ce niveau est reporté et noté lors de l'évaluation.

uI = N.Ind total ÷ nombre de critères ÷ 3
N.Ind = Σ (niveau observé × uI) pour chaque critère
Exemple (3AC, N.Ind total=6, 2 critères) — uI = 6÷2÷3 = 1pt. Élève : Niveau 3 au critère A, Niveau 2 au critère B :
N.Ind = (3×1) + (2×1) = 5/6
3. Note collective — N.Col

Commune à tous les élèves d'un même groupe. Elle se répartit en trois composantes de la grille collective : 50% critère collectif observé (niveau 1/2/3) + 25% gain du match (Perdu/Gagné) + 25% motivation & coopération (Non/Oui).

uCC = (N.Col total × 0,50) ÷ 3  →  critère : niveau × uCC
uGain = (N.Col total × 0,25) ÷ 2  →  Perdu = 1×uGain · Gagné = 2×uGain
uMotiv = (N.Col total × 0,25) ÷ 2  →  Non = 1×uMotiv · Oui = 2×uMotiv
N.Col = (critère) + (gain) + (motivation)
Exemple (3AC, N.Col total=6 → uCC=1 · uGain=0,75 · uMotiv=0,75) — Groupe : Niveau 2 au critère collectif, match Gagné, motivation Oui :
N.Col = (2×1) + (2×0,75) + (2×0,75) = 2+1,5+1,5 = 5/6
• Le N.Col est identique pour tous les élèves d'un même groupe ; seul le N.Ind varie individuellement selon le niveau observé sur les critères personnels.
• Cliquer sur « 🔄 Calculer les notes procédurales » fige N.Ind/N.Col dans le bulletin de l'élève.

📖 Méthodologie de l'évaluation — Gymnastique au sol
Comment l'application calcule la note procédurale (/14 · /13 · /12) d'un cycle de gymnastique au sol, selon le barème officiel du Ministère. Elle est composée de trois parties additionnées directement : Difficulté + Composition + Exécution.
1. Répartition générale
Note procédurale = Difficulté + Composition (Exigences spécifiques + Qualité d'enchaînement) + Exécution
NiveauComp.Concert.DifficultéCompositionExécutionProcédurale
1AC/3/3/6/6 (1,5 + 4,5)/2/14
2AC/4/3/6/5 (1,5 + 3,5)/2/13
3AC/5/3/6/4 (1,5 + 2,5)/2/12
Principe d'action par niveau : 1AC — 3A 2B 0C · 2AC — 3A 2B 1C · 3AC — 2A 4B 1C (combinaison d'éléments exigée pour la note de Difficulté).
2. Difficulté (/6) — éléments A / B / C

Chaque élève sélectionne des éléments gymniques (parmi les 8 familles officielles) dans la grille « Difficulté ». Pour chaque catégorie (A, B, C), on ne compte les éléments réalisés que jusqu'au nombre exigé par le niveau — les éléments en plus ne rapportent rien de plus. Chaque élément compté vaut le nombre de points indiqué dans le tableau ci-dessous.

NiveauNombre A exigéNombre B exigéNombre C exigéPts / élément APts / élément BPts / élément C
1AC3201,001,50—
2AC3210,751,001,75
3AC2410,500,752,00
Exemple (3AC) — un élève réalise 2 éléments A, 4 éléments B et 1 élément C (soit exactement le nombre exigé par le niveau) :
2 éléments A × 0,50 pt = 1 pt · 4 éléments B × 0,75 pt = 3 pts · 1 élément C × 2,00 pt = 2 pts.
Total Difficulté = 1 + 3 + 2 = 6/6
3. Composition — Exigences spécifiques + Qualité d'enchaînement

La Composition regroupe deux éléments : la diversité des familles gymniques utilisées, et la qualité d'exécution de l'enchaînement observée en direct.

a) Exigences spécifiques (/1,5)

C'est un bonus de diversité : plus l'élève puise ses éléments dans des familles gymniques différentes (parmi les 8 familles officielles), plus il gagne de points, jusqu'à un maximum de 3 familles comptées.

Familles différentes utilisées123 ou plus
Points obtenus0,51,01,5 (maximum)
b) Qualité d'enchaînement (4,5 en 1AC · 3,5 en 2AC · 2,5 en 3AC)

Observée en direct sur 3 critères (Rythme/fluidité, Amplitude, Aisance/liaisons). Pour chaque critère, on clique sur la pastille de la grille pour situer l'élève à un niveau 1, 2 ou 3. Le maximum du niveau est partagé également entre les 3 critères, et chaque critère rapporte une part proportionnelle à son niveau (Niveau 3 = part complète, Niveau 2 = 2/3 de la part, Niveau 1 = 1/3 de la part).

Exemple (3AC, maximum 2,5 réparti sur 3 critères ≈ 0,83 chacun) — un élève est jugé Niveau 3 sur les 3 critères (le maximum) :
3 critères × 0,83 pt (part complète) = 2,5/2,5
4. Exécution (/2) — fautes et chutes

L'élève part de 2 points. On retire une pénalité à chaque faute observée pendant l'enchaînement (jamais en dessous de 0).

Type de fautePénalité
Petite faute-0,1
Faute moyenne-0,2
Faute grossière-0,3
Chute-0,5
Exemple — un élève a 2 petites fautes et 1 chute :
Pénalités = (2 × 0,1) + (1 × 0,5) = 0,2 + 0,5 = 0,7 pt retiré.
Exécution = 2 − 0,7 = 1,3/2
• Note procédurale = Difficulté + Composition (Exigences + Enchaînement) + Exécution.
• Cliquer sur « 🔄 Calculer les notes procédurales » fige cette note dans le bulletin de l'élève.
